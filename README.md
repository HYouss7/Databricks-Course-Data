# Databricks-Course-Data

## Overview

This repository contains all the source code used in the Databricks course. Here you will find notebooks, SQL scripts, Python code, and supporting materials referenced throughout the lessons.

## Repository Structure

- **Notebooks** – Databricks notebooks covering data engineering, SQL, and machine learning topics
- **Scripts** – Standalone Python and SQL scripts used in the course
- **Data** – Sample datasets referenced in the examples and exercises
- **Solutions** – Answer keys for course exercises and assignments

## Getting Started

1. **Clone the repository** to your local machine or directly into your Databricks workspace:
   ```bash
   git clone https://github.com/your-username/Databricks-Course-Data.git
   ```
2. **Import notebooks** into your Databricks workspace using the **Repos** feature or by importing individual `.py` / `.ipynb` files.
3. **Attach a cluster** and run the notebooks in the recommended order.

## Prerequisites

- A Databricks workspace (Community Edition or a paid Databricks account)
- Basic knowledge of Python and SQL
- Familiarity with Apache Spark concepts (helpful but not required)

## Usage

Feel free to follow along with the course at your own pace. Each notebook is self-contained and includes comments explaining the concepts covered. If you are enrolled in the course, work through the materials in the order presented in the curriculum.
